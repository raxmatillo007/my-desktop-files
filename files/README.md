# 🎬 Kino Bot

## O'rnatish
1. Python 3.10+ o'rnatilgan bo'lsin.
2. `pip install -r requirements.txt`
3. `.env.example` ni `.env` ga nusxalang va to'ldiring (BOT_TOKEN, ADMINS).
4. `python bot.py`

## Ishlatish
- Admin: `/admin` - kino qo'shish, o'chirish, kanallar, statistika, xabar yuborish.
- Majburiy obuna: admin paneldan kanal qo'shing (bot kanalda ADMIN bo'lishi shart).
- Foydalanuvchi: kino kodini yuboradi yoki nomini yozib qidiradi.
